## PacMan like

Vamos a crear un juego de PacMan como el juego de PacMan original, pero con una interfaz gráfica más moderna y sencilla.

## Tecnologías

- Vanilla JS
- HTML
- CSS

# Spec Driven Development

El proyecto sirve para aprender este enfoque de desarrollo.
